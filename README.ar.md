# دوائي — تطبيق التذكير بالدواء

تطبيق أندرويد بسيط بالعربية، **يعمل بدون إنترنت نهائياً**، مصمّم ليكون سهلاً على كبار السن.

---

## الفكرة

- كل حبة تأخذها **تنزل داخل علبة زجاجية** تتجمّع فيها حبوبك — كل دواء بلونه وشكله (كبسولة، قرص، شراب، إبرة، قطرة).
- في صفحة كل دواء يظهر **شريط الحبوب المتبقية**؛ كلما أخذت جرعة **يُفتح جيب** من الشريط حتى ينتهي الكورس العلاجي.
- يدعم **أكثر من مريض**، ولكل مريض علبته وأدويته وسجله.

---

## المميزات

| الميزة | التفاصيل |
|---|---|
| المنبه القوي | شاشة كاملة تفتح لوحدها + صوت مستمر (يتوقف بعد دقيقتين تلقائياً) + اهتزاز، تعمل فوق شاشة القفل |
| الإشعار الهادئ | إشعار عادي بصوت قصير — يُختار لكل دواء على حدة |
| أزرار الإشعار | «أخذت الدواء» و«تأجيل» مباشرة من الإشعار |
| بدون إنترنت | لا يوجد أي اتصال بالشبكة، كل البيانات في قاعدة بيانات محلية على الهاتف |
| العربية | الواجهة كاملة عربية من اليمين لليسار، مع أرقام عربية (٠١٢٣) قابلة للإطفاء |
| كبار السن | خطوط كبيرة، أزرار كبيرة (٦٠–٨٠ بكسل)، ثلاثة أحجام للخط |
| المخزون | تنقص الكمية تلقائياً، وتنبيه عند اقتراب النفاد، وزر «تعبئة كمية جديدة» |
| الجدولة | أوقات متعددة يومياً، أيام أسبوع محددة، مدة كورس (أو مستمر) |

## التشغيل

```bash
flutter pub get

```

### بناء ملف APK للتثبيت على الهاتف

```bash
flutter build apk --release --split-per-abi
```

الملف الناتج في: `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`

> للنشر على المتجر لاحقاً: أنشئ مفتاح توقيع خاص بك وعدّل `signingConfig` في
> `android/app/build.gradle.kts` (حالياً يستعمل مفتاح التصحيح).

## أذونات مهمة على الهاتف

عند أول تشغيل سيطلب التطبيق الأذونات. إن لم يرن المنبه في وقته، افتح
**الإعدادات ← تفعيل الأذونات** داخل التطبيق، وتأكد من:

1. **الإشعارات** مفعّلة للتطبيق.
2. **المنبهات والتذكيرات الدقيقة** (Alarms & reminders) مسموحة.
3. **إيقاف تحسين البطارية** للتطبيق (مهم جداً على Xiaomi / Huawei / Oppo / Samsung، وإلا يوقف النظام المنبهات).
4. **التنبيهات بملء الشاشة** مسموحة (أندرويد ١٤ فما فوق).

يوجد زرّا **تجربة المنبه** و**تجربة الإشعار** في الإعدادات للتأكد من الصوت.

## ملاحظات تقنية

- **الجدولة**: يُجدول التطبيق مواعيد العشرة أيام القادمة (حتى ٣٨٠ تنبيهاً) ويعيد بناءها
  عند كل تعديل أو عند فتح التطبيق، مع إعادة الجدولة تلقائياً بعد إعادة تشغيل الهاتف.
- **المنطقة الزمنية**: تُضبط تلقائياً من إعدادات الهاتف بدون أي اتصال بالشبكة.
- **الصوت المستمر**: عبر `FLAG_INSISTENT` مع قناة إشعارات من نوع «منبه»، فيستعمل مستوى صوت المنبه.
- **الحبوب المأخوذة** تُخزَّن مع لون الدواء وشكله واسمه، لذا تبقى داخل العلبة حتى لو حُذف الدواء.
